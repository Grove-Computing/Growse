# Growse v0.5.0 スコープ定義書

## 1. 文書概要

本書は、Growse v0.5.0で実装するCSS Flexible Box Layoutの範囲、完了条件、および対象外を定義する。

v0.5.0はv0.4.0のCSS AST、Cascade、Value、Box Model、およびSizingが完成していることを前提とする。

---

## 2. リリーステーマ

> **一次元レイアウトを、CSSの意図どおり柔軟に配置できるブラウザへ。**

W3C CSS Flexible Box Layout Module Level 1とCSS Box Alignment Module Level 3を基準に、horizontal writing modeにおけるFlex formatting contextを実装する。

---

## 3. 目標

1. `flex`と`inline-flex`のFormatting Contextを生成する
2. main axisとcross axisを明示的に扱う
3. flex basis、free space、grow、shrinkを仕様順に解決する
4. wrapping、alignment、auto margin、gapを扱う
5. min/max size、intrinsic size、aspect ratioとFlex sizingを統合する
6. nested flex containerと動的DOM変更を扱う
7. Layout、Paint、Hit Testing、Scrollを同じFlex geometryへ一致させる

## 5. Flex Layout Algorithm

次の段階を独立した処理として実装する。

1. Flex itemの収集とAnonymous Flex Itemの生成
2. `order`によるorder-modified document order
3. main/cross axisとavailable spaceの決定
4. flex base sizeとhypothetical main sizeの決定
5. Flex lineの形成
6. flexible lengthの解決
7. min/max constraintとautomatic minimum sizeの適用
8. cross sizeとbaselineの決定
9. main axis alignment
10. cross axis alignment
11. auto marginとgapの反映
12. 最終Box geometryの生成

浮動小数の丸め誤差で総幅がContainer幅と不整合にならないよう、余りの割当方法を決定的にする。

---

## 6. Intrinsic Sizeと制約

- min-content / max-content contributionを区別する
- replaced elementとtext itemのintrinsic sizeを扱う
- `min-width: auto`のFlex item向け挙動を扱う
- percentage flex-basisのContaining Blockを正しく選択する
- indefinite sizeではpercentageを仕様に従ってauto相当へFallbackする
- width、height、min/max、box-sizing、aspect-ratioの順序を固定する
- overflowがautomatic minimum sizeへ与える影響を扱う

---

## 7. DOM、Interaction、Accessibility

- `order`は視覚順だけを変更し、DOM順とWebGoの探索順を変更しない
- Keyboard focus順はDOM順を維持する
- Screen reader向け意味順を視覚順へ上書きしない
- Hit Testingは最終的なPaint順とFlex item geometryを利用する
- `display:none`のitemをFlex layoutへ含めない
- `:hover`、`:focus`、WebGo mutationでFlex propertyが変わった場合は次のLayoutで再計算する
- 削除されたFlex itemの古いHit Test領域を残さない

---

## 8. PaintとOverflow

- Flex itemのbackground、border、radius、opacityを通常Boxと同じ規則で描画する
- itemの描画順はorder-modified document orderを基準とする
- z-indexを持たないitemでは安定したDOM由来順を維持する
- Containerのoverflow clipとscroll extentへ全Flex lineを反映する
- reverse方向でもScroll OriginとHit Testingを一致させる
