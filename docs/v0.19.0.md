# Growse v0.19.0 スコープ定義書

## 1. 文書概要

本書は、Growse v0.19.0で実装する **CSS Layout 2026 Baseline、実用Webレイアウト、仕様適合** の範囲、完了条件、対象外を定義する。

v0.19.0は、v0.18.0までに完成したBrowser-grade Resource Loading、独自DOM / CSS / Layout / Paint、JavaScriptによる動的更新、固定framework corpusを前提とする。既存のBlock / Inline、Float、Table、Flexbox、Grid、Position、Overflow、logical property実装を個別機能の集合から相互運用可能なlayout systemへ統合する。

「CSSレイアウトの完全実装」はCSS全仕様を無制限に実装する意味ではない。本Releaseでは、一般的なscreen向けWeb Pageに必要なCSS 2.1 Visual Formatting、CSS Sizing、Box Alignment、Flexbox Level 1、Grid Level 1とSubgrid、Writing Modes、Positioned Layout、Overflow、Multi-columnの本書記載範囲を **CSS Layout 2026 Baseline** と定義する。

---

## 2. リリーステーマ

> **通常flow、intrinsic sizing、Table、Flex、Grid / Subgrid、Writing Mode、Sticky、Overflow、Multi-columnを同じgeometry modelで動かし、実サイトと選定WPTの双方で壊れないCSS Layoutへ。**

利用者はdesktop / narrow viewport、日本語 / Latin、動的DOM更新、scrollを含むPageで、要素の重なり、欠落、極端なはみ出し、操作位置のずれを避けられる。開発者はLayout Tree、Paint、Hit Testing、Scroll extentが同じgeometryを参照し、Chromium / Firefoxとの差を固定fixtureで再現できる。

## 4. 目標

1. Block / Inline Formatting Context、margin collapsing、float / clear、shrink-to-fit、containing blockを一貫したflow geometryへ統合する
2. intrinsic sizing、percentage、min / max、aspect-ratio、replaced element、Table sizingをfiniteかつ決定的に解決する
3. Flexbox Level 1、Grid Level 1、Subgrid、Box Alignmentをnested layoutとWriting Modeで相互運用する
4. horizontal / vertical Writing Modeとlogical propertyをLayout、Paint、Hit Testing、Scrollへ接続する
5. relative / absolute / fixed / sticky、nested scroll container、overflow clip / extentを同じcontaining block modelで扱う
6. Multi-columnと基本Fragmentationをscreen向けlayoutへ追加する
7. DOM / stylesheet / viewport mutation後のreflowを安定化し、選定WPT、実framework corpus、公開site、desktop実機で検証する

## 5. Flow Formatting Context

### 5.1 Block Formatting Context

Block boxはnormal flow、anonymous box、`display:contents`、float、absolute childを区別する。親子と隣接Blockの正負margin collapsing、clearance、BFC境界、auto margin、shrink-to-fitを扱う。Floatは左右配置、複数float、clear、inline内容の回り込みを扱い、BFC外へ状態を漏らさない。

### 5.2 Inline Formatting Context

Inline text、atomic inline、inline-block、inline-flex、inline-grid、replaced elementをline boxへ配置する。white-space、word wrapping、line-height、baseline、vertical-align、text-indent、letter / word spacingを使い、混在runと折返し後もPaint / Hit Testing geometryを一致させる。

### 5.3 Containing Blockと安全上限

Formatting Contextごとにcontaining blockとavailable sizeを明示し、indefinite percentageと循環依存を有限fallbackへ変換する。Layout recursion、generated fragment、line、float、anonymous boxへ上限を設け、超過時はPage全体をpanicさせず対象subtreeを診断付きで打ち切る。

---

## 6. Sizing、Replaced Element、Table

### 6.1 Sizing

`auto`、length / percentage、`min-content`、`max-content`、`fit-content`、min / max、`box-sizing`をBlock、Inline Block、Table、Flex item、Grid item、replaced elementで扱う。percentage heightはdefinite containing blockだけから解決し、content-based minimum sizeとaspect-ratio transferをlayout mode間で一貫させる。

### 6.2 Replaced Element

`img`、`picture`、form control、iframeはintrinsic width / height / ratio、HTML dimension attribute、CSS sizing、min / max、object-fit / positionを順序どおり解決する。Resourceのlate completionは対象geometry、ancestor intrinsic contribution、scroll extentを更新する。

### 6.3 Table Formatting

table、caption、row group、row、column group、column、cellのanonymous wrapper生成を扱う。`table-layout:auto|fixed`、column width、cell min / max contribution、colspan / rowspan、border spacing、border collapse、caption side、vertical alignmentをscreen layoutへ接続する。

---

## 7. Flexbox、Grid、Box Alignment

### 7.1 Flexbox Level 1

main / cross axis、single / multi-line、reverse、grow / shrink freeze、flex-basis、automatic minimum size、aspect-ratio、baseline、auto margin、gap、order、absolute childのstatic positionを扱う。Nested Flex / Grid、intrinsic container、percentage size、overflow itemでもfinite geometryを生成する。

### 7.2 Grid Level 1とSubgrid

explicit / implicit grid、named line、area、span、dense / sparse auto-placement、intrinsic / flexible track sizing、`minmax()`、`fit-content()`、`repeat()`、auto-fill / auto-fit、alignmentを扱う。Subgridは親のcolumn / row trackとgapを継承し、nested itemのintrinsic contributionとplacementを親track sizingへ反映する。

Masonryは対象外とし、`masonry`値を無効な宣言として局所化する。

### 7.3 Box Alignment

`justify-*`、`align-*`、`place-*`、baseline、safe / unsafe、start / end / self-start / self-end、space distribution、gapをBlockの適用可能範囲、Flex、Grid、Subgridへ接続する。Writing Modeとdirectionに応じてphysical axisへ写像する。

---

## 8. Writing ModeとLogical Geometry

`writing-mode:horizontal-tb|vertical-rl|vertical-lr`、`direction:ltr|rtl`をcomputed styleへ保持する。inline / block axisをLayout全体で明示し、logical size、margin、padding、border、inset、float、clear、alignment、overflow、scroll extentをphysical geometryへ変換する。

Vertical Writing Modeではline progression、glyph orientationの安全なsubset、replaced element、Flex / Grid axis、sticky inset、Hit Testingを扱う。完全なUnicode bidi algorithm、text-orientationの全値、縦中横、Rubyは対象外とし、未対応text shapingをgeometry破綻やpanicへ波及させない。

---

## 9. Position、Overflow、Scroll

relative、absolute、fixed、stickyについてpadding box / scrollport / initial containing blockを区別し、inset、auto size、opposing inset、percentage、z-indexを解決する。Stickyは上下左右、両軸、nested scroll container、oversized sticky box、container終端を扱う。

`overflow:visible|hidden|clip|auto|scroll`とaxis shorthandをclip、scroll extent、scroll offset、Paint、Hit Testingへ共有する。Scrollbar gutterの基本geometryを予約し、scrollbar UI自体はplatform widgetの対応範囲に限定する。Transform、nested clip、rounded clipの内外でpointer対象を一致させる。

---

## 10. Multi-columnとFragmentation

`column-count`、`column-width`、`columns`、`column-gap`、column rule、`column-span:all`、`column-fill:auto|balance`を扱う。Block / inline contentをcolumn fragmentへ分割し、`break-before`、`break-after`、`break-inside`の主要値、widow / orphanの安全なsubsetを適用する。

FragmentはDOM node identityを維持したまま複数visual boxを持ち、Paint順、clip、Hit Testing、selection対象、scroll extentへ共有する。Fragment数とbalancing iterationへ上限を設け、収束しない場合は有限なauto-fillへfallbackする。

---

## 11. 動的Reflow、実サイト品質、仕様適合

DOM mutation、class / style変更、stylesheet追加、font / image completion、viewport resize、scroll container resize後に、影響subtreeとancestor contributionを更新する。Layout、Display List、Hit Testing、Inspector snapshotを同じrevisionから生成し、stale resource completionを破棄する。

Next.js / SvelteKit / Tailwindの固定corpusへLayout stress routeを追加し、desktop / narrow、horizontal / vertical、resource completion前後、hydration前後、scroll前後を検証する。代表的な公開siteはmanual desktop gateで用い、CIはoffline fixtureだけで決定的に実行する。

WPTはupstream harness全体を直接実行せず、仕様節、upstream path、revisionを記録したassertionをGrowseのcomputed style、fragment geometry、scroll extent、hit testへ適応する。ChromiumとFirefoxの固定referenceから許容差を定義し、差分を黙ってbaseline更新しない。

---

## 12. テスト方針

- Unit Test: Formatting Context、sizing equation、table track、flex freeze、grid / subgrid track、axis mapping、sticky constraint、fragmentationをtable-drivenで検証する
- Integration Test: nested layout、resource late completion、DOM / stylesheet mutation、viewport resize、scroll、Paint / Hit Testing共有geometryを検証する
- Visual Regression: desktop / narrow、horizontal / vertical Writing Mode、Table / Flex / Grid / Multi-column、sticky scrollを固定font・scale・clockで比較する
- Conformance Test: CSS 2.1、Flexbox、Grid、Writing Modes、Position、Overflow、Multi-columnから選定したWPT assertionを固定revisionで適応する
- Differential Test: 同一offline fixtureをChromium / Firefox / Growseで取得し、主要landmark geometry、scroll extent、screenshot regionを比較する
- Desktop E2E: 各大項目PRと最終release HEADを`go run ./cmd/growse`で起動し、computer useでresize、scroll、link、form、dynamic mutation、Back / Reload、Tabを操作する

## 13. Showcase

`examples/css-layout-2026`を追加し、単一のlocal serverで次を切り替えられるようにする。

- Flow: margin collapse、float / clear、inline wrapping、atomic inline、BFC
- Sizing / Table: intrinsic keyword、aspect ratio、replaced element、auto / fixed table、span
- Flex / Grid: wrap、baseline、nested layout、Subgrid、alignment
- Writing: horizontal-tb、vertical-rl、vertical-lr、logical property
- Position / Overflow: absolute / fixed / sticky、nested scroll、clip / extent
- Columns: count / width、balance、span、break control
- Dynamic: class mutation、content追加、image completion、viewport resize後のreflow

各sectionは期待geometryを画面内statusとして表示し、JS Engineで操作できる。Go Engineでは静的SSR部分を表示し、JavaScript callbackを開始しない。

## 14. 実装フェーズ

### Phase 1 — Flow Formatting Context

Block / Inline Formatting Context、margin collapse、float / clear、shrink-to-fit、line box、containing block、安全上限を統合する。

### Phase 2 — Sizing、Replaced Element、Table

intrinsic / percentage / aspect-ratio sizing、late resource reflow、Table formatting algorithmを実装する。

### Phase 3 — Flexbox、Grid、Subgrid、Alignment

Flexbox Level 1とGrid Level 1のedge caseを収束させ、SubgridとWriting Mode対応Box Alignmentを追加する。

### Phase 4 — Writing ModeとLogical Geometry

logical axis model、vertical-rl / vertical-lr、direction、logical propertyをLayout / Paint / Hit Testing / Scrollへ接続する。

### Phase 5 — Position、Overflow、Scroll

containing block、両軸Sticky、nested scroll container、overflow axis、clip / extent / hit-testを統合する。

### Phase 6 — Multi-columnとFragmentation

column sizing、content fragmentation、span、break control、fragment paint / hit-testを実装する。

### Phase 7 — Conformance、Showcase、Release品質

選定WPT、Chromium / Firefox differential、framework corpus、documentation、performance / safety gate、computer useによるdesktop実機検証を完成させる。

## 15. v0.19.0 非対象

- Print / Paged Media、page margin box、CSS Regions、CSS Shapes、Exclusions
- Ruby、縦中横、text-orientation全値、完全なUnicode bidi / line breaking / hyphenation
- Masonry Layout、Anchor Positioning、View Transitions、Scroll-driven Animationなど策定中またはlayout外の機能
- SVG layout全体、MathML layout、Canvas、WebGL / WebGPU、native widgetの全platform pixel parity
- Chromium、Firefox、WebKit、WebViewの埋め込みまたはlayout委譲
- 任意公開site、全WPT、全CSS仕様とのpixel完全一致
- tag pushまたはGitHub Release公開
