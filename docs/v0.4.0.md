# Growse v0.4.0 スコープ定義書

## 1. 文書概要

### 1.1 対象バージョン

```text
Growse v0.4.0
```

### 1.2 本書の目的

本書は、Growse v0.4.0で実装するCSS3 Coreの範囲、完了条件、および対象外とする機能を定義する。

CSS3は単一仕様ではなくモジュール群であるため、本書では「CSS3完全対応」という曖昧な表現を使用しない。v0.4.0は、一般的な文書レイアウトに必要な構文、Selector、Cascade、Value、Box Model、Text、およびMedia Queryの基盤を完成させるリリースとする。

JavaScriptエンジン、WebAssembly、WebView、および既存ブラウザエンジンは使用しない。

---

## 2. リリーステーマ

> **CSSを文字列ではなく型として理解し、一般的な文書を正しく組版できるブラウザへ。**

v0.3.0までのCSS実装は、単純Selectorと少数のPropertyを直接Computed Styleへ変換するMVPである。v0.4.0ではCSS処理をSyntax、Selector、Cascade、Value、Computed Style、Layout、Paintへ分離し、以後のFlexboxとGridを追加できる基盤へ再構成する。

---

## 3. 準拠基準

実装判断では、次のW3C仕様のうち本書で明示した範囲を基準とする。

- CSS Syntax Module Level 3
- Selectors Level 3
- CSS Cascading and Inheritance Level 3
- CSS Values and Units Module Level 3
- CSS Color Module Level 3
- CSS Color Module Level 4のうちsRGB 4/8桁16進表記
- CSS Box Model Module Level 3
- CSS Backgrounds and Borders Module Level 3
- CSS Fonts Module Level 3
- CSS Text Module Level 3
- Media Queries Level 3
- CSS Style Attributes

仕様全体への適合を宣言するのではなく、対応Featureをテスト名と完了条件で明示する。解釈が競合する場合はW3C仕様とWeb Platform Testsを優先する。

---

## 4. 目標

1. CSS TokenとValueを型付きモデルとして保持する
2. Selectors Level 3の主要SelectorとCombinatorを扱う
3. Author、Inline、UA、`!important`、詳細度、ソース順を含むCascadeを扱う
4. CSS-wide keyword、継承、およびCustom Propertyを扱う
5. 一般的な長さ、割合、色、`calc()`をComputed Valueへ解決する
6. width、height、border、box-sizingを含むBox Modelを実装する
7. TextとFontの主要Propertyを描画へ反映する
8. viewportに対するMedia Queryを評価する
9. CSSエラーを局所的に回復し、残りのページ表示を継続する
10. v0.3.0までの操作、WebGo、およびデモを回帰させない

---

## 5. CSSモデルの再設計

### 5.1 処理段階

```text
CSS bytes
  -> Token / Rule parsing
  -> Selector AST / Declaration AST
  -> Selector matching
  -> Cascaded values
  -> Specified values
  -> Computed values
  -> Used values
  -> Layout Tree
  -> Display List
```

Declarationの値を早期に`float32`へ潰さない。割合や相対単位をContaining Block、Font、Viewportが確定するまで保持できるモデルにする。

### 5.2 Value型

少なくとも次の区別を型として保持する。

- Keyword
- Number / Integer
- Length
- Percentage
- LengthPercentage
- Color
- String
- URL
- Function
- Custom Property Token Stream

未対応Propertyは構文解析後も安全に保持または無視できるようにし、未知PropertyだけでStylesheet全体を失敗させない。

### 5.3 CSSエラー回復

- 不正DeclarationはそのDeclarationだけを破棄する
- 不正Selector Listは仕様に従ってRuleを無効化する
- 未知Propertyと未知At-ruleは安全に無視する
- 括弧、文字列、コメント内の区切り文字を誤認しない
- CSSエラーだけでNavigationまたはGrowseプロセスを終了しない

## 6. Selector

### 6.1 対応Selector

- Type Selector: `article`
- Universal Selector: `*`
- ID Selector: `#app`
- Class Selector: `.card`
- Compound Selector: `article.card.featured`
- Attribute presence: `[disabled]`
- Attribute comparison: `[type="text"]`、`[lang|="ja"]`、`[class~="item"]`
- Attribute prefix/suffix/substring: `^=`、`$=`、`*=`
- Descendant Combinator: `main p`
- Child Combinator: `main > p`
- Adjacent Sibling Combinator: `h2 + p`
- General Sibling Combinator: `h2 ~ p`
- Selector List: `h1, h2, h3`

### 6.2 対応Pseudo-class

- `:root`
- `:empty`
- `:first-child` / `:last-child` / `:only-child`
- `:first-of-type` / `:last-of-type` / `:only-of-type`
- `:nth-child()` / `:nth-last-child()`
- `:nth-of-type()` / `:nth-last-of-type()`
- `:not()`のSelectors Level 3形式
- `:link`
- `:hover`
- `:focus`
- `:enabled` / `:disabled`
- `:checked`

### 6.3 Pseudo-element

v0.4.0では`::before`と`::after`を、`content`が文字列または`none`の場合に限定して対応する。生成内容もLayout TreeとHit Testingへ一貫して反映する。

### 6.4 詳細度

ID、Class・Attribute・Pseudo-class、Type・Pseudo-elementの各成分を仕様どおり計算する。Selector Listでは一致したSelectorごとに詳細度を評価する。

---

## 7. CascadeとInheritance

### 7.1 Style Source

次をCascadeへ入力する。

1. Growse UA Stylesheet
2. `<style>`
3. 同一オリジンの外部Stylesheet
4. 要素の`style`属性

優先順位はOrigin、Importance、詳細度、およびソース順に基づいて決定する。v0.4.0ではUser StylesheetとCascade Layerは導入しない。

### 7.2 Global Keyword

- `inherit`
- `initial`
- `unset`

`revert`と`revert-layer`は対象外とする。

### 7.3 Custom Property

- `--name`形式のCustom PropertyをCascade・継承できる
- `var(--name)`とFallbackを解決できる
- 循環参照を検出し、該当Declarationをinvalid at computed-value timeとして扱う
- Custom Property名の大文字小文字を区別する
- WebGoによる属性・class変更後も再評価できる

---

## 8. Values、Units、Color

### 8.1 Length

- Absolute: `px`、`in`、`cm`、`mm`、`q`、`pt`、`pc`
- Font-relative: `em`、`rem`、`ex`、`ch`
- Viewport-relative: `vw`、`vh`、`vmin`、`vmax`
- Percentage
- 単位なしの`0`

### 8.2 Calculation

互換なDimension間で次を扱う。

- `calc()`
- 加算、減算、乗算、除算
- 括弧
- 正負号

ゼロ除算、非互換Dimension、および非有限値はDeclarationを無効とする。

### 8.3 Color

- CSS Color Level 3のNamed Color
- `transparent`
- `currentColor`
- `#rgb` / `#rgba` / `#rrggbb` / `#rrggbbaa`
- `rgb()` / `rgba()`
- `hsl()` / `hsla()`
- alpha channel

## 9. 対応Property

### 9.1 DisplayとSizing

- `display: none | inline | block | inline-block`
- `visibility: visible | hidden | collapse`
- `width` / `height`
- `min-width` / `min-height`
- `max-width` / `max-height`
- `box-sizing: content-box | border-box`
- `overflow` / `overflow-x` / `overflow-y`: `visible | hidden | auto | scroll`

### 9.2 Box Model

- `margin`と4方向Longhand
- `padding`と4方向Longhand
- `border`とwidth/style/colorのShorthand・Longhand
- `border-radius`
- block方向のmargin collapsing
- percentage margin / padding
- `auto` margin

### 9.3 Background

- `background-color`
- 単一の`background-image: url(...) | none`
- 単一の`linear-gradient()`
- `background-repeat`
- `background-position`
- `background-size`

複数Background Layerはv0.4.0の対象外とする。

### 9.4 FontとText

- `font-family`
- `font-size`
- `font-style`
- `font-weight`
- `line-height`
- `text-align`
- `text-decoration-line`
- `text-decoration-color`
- `text-transform`
- `white-space`
- `word-break`
- `overflow-wrap`
- `letter-spacing`
- `word-spacing`
- `vertical-align`のinline向け主要値
- `color`
- `opacity`

利用できないFont FamilyはGioのFallbackへ安全に委譲する。v0.4.0ではネットワークFontを読み込まない。

## 10. Media Query

### 10.1 対応At-rule

- `@media`
- 同一オリジンの`@import`

`@import`はStylesheet先頭の有効な位置だけで処理し、Media Query付きImportを評価する。循環参照、最大深度、総取得数、および取得サイズを制限する。

### 10.2 対応Media

- `all`
- `screen`
- `not` / `only`
- comma-separated query list

### 10.3 対応Feature

- `width` / `min-width` / `max-width`
- `height` / `min-height` / `max-height`
- `orientation`
- `resolution` / `min-resolution` / `max-resolution`
- `prefers-color-scheme`
- `hover`
- `pointer`

ViewportまたはMetricが変化した場合だけMedia Queryを再評価し、必要なStyle・Layout・Paintを更新する。

---

## 11. LayoutとPaint

### 11.1 Layout

- Content、Padding、Border、Marginの各Boxを明示する
- width/heightのauto・percentage・min/max制約を解決する
- inline-blockをAtomic Inlineとして配置する
- 実フォント計測を使用してLine Boxを構築する
- line-height、baseline、white-space、改行を反映する
- overflow領域とClippingをLayout結果へ保持する
- `display:none`要素はLayout、Paint、Hit Testingから除外する

### 11.2 Paint

Display Listへ少なくとも次を追加する。

- Box background
- Border
- Rounded clip
- Background image / gradient
- Text decoration
- Opacity layer
- Overflow clip

描画順序はbackground、border、children/content、outline相当の順序を固定し、DOM順だけに依存しない。

---

## 12. SecurityとResource Loading

- StylesheetとBackground Imageは既存のNetwork制限、サイズ制限、Content-Type検証に従う
- `@import`は同一オリジンだけを許可する
- `@import`の循環、最大深度、総取得数を制限する
- `data:` URLは画像用途の安全なMIME Typeとサイズ上限を満たす場合だけ許可する
- CSS URLをログへ出す場合は認証情報を秘匿する
- CSS解析または画像Decodeの失敗だけでプロセスを終了しない

## 13. テスト方針

### 13.1 Unit Test

- Token、Escape、Comment、String、Functionの解析
- Selector AST、Matching、詳細度
- `an+b`の解析とSibling位置判定
- CascadeのOrigin、Importance、Inline、詳細度、ソース順
- CSS-wide keywordとPropertyごとのInheritance
- Custom PropertyのFallbackと循環検出
- Unit、Percentage、`calc()`、Colorの変換
- Shorthand展開とDeclaration単位のエラー回復
- Media Queryの評価
- Box sizingとmargin collapsing

### 13.2 Integration Test

- HTML、inline style、`<style>`、外部CSSを結合したCascade
- viewport resizeによるMedia Query切替
- WebGoのclass・attribute変更後のSelector再評価
- Font計測を使ったinline wrapping
- Background、Border、Text Decoration、OpacityのDisplay List
- overflow clipとHit Testingの一致

### 13.3 Conformance Test

対応FeatureごとにWeb Platform Testsから再配布可能なTestを選定し、期待値と出典を記録する。未対応Featureを誤って対応済みと扱わないため、対応表を`docs/`に維持する。
