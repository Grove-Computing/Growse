# Growse v0.7.0 スコープ定義書

## 1. 文書概要

本書は、Growse v0.7.0で実装するCSS Transitions、CSS Animations、および時間駆動の描画更新基盤の範囲、完了条件、および対象外を定義する。

v0.7.0は、v0.6.0のGrid、Positioned Layout、Stacking Context、2D Transform、Opacity、Display List、およびVisual Regression Testが完成していることを前提とする。

JavaScript、Web Animations API、WebView、および既存ブラウザエンジンは使用しない。

---

## 2. リリーステーマ

> **静的な画面から、時間に沿って滑らかに変化するWebアプリケーションを描けるブラウザへ。**

CSSの状態変化を即座に最終値へ切り替えるだけでなく、開始時刻、遅延、継続時間、Easing、繰り返し、および終了後の状態を明示的に扱う。

Animationの各FrameでStyle、Display List、Paint、およびHit Testingが同じ時刻の値を参照し、WebGo mutationやhoverによる状態変化と安全に統合する。

---

## 3. 準拠基準

本書で明示した範囲について、次を基準とする。

- CSS Transitions Level 1
- CSS Animations Level 1
- CSS Easing Functions Level 1
- Web Animations Level 1のTiming Model
- CSS Transforms Module Level 1
- CSS Color Module Level 4のうちsRGB Color interpolation
- Media Queries Level 5のうち`prefers-reduced-motion`

Web Animations APIを公開することや、各仕様全体への適合は宣言しない。仕様と実装判断が競合する場合は、対応範囲内のW3C仕様とWeb Platform Testsを優先する。

---

## 4. 目標

1. 単調増加するClockを基準にAnimationの現在時刻を決定する
2. Computed Styleの変更からCSS Transitionを開始できる
3. `@keyframes`と`animation-*`からCSS Animationを生成できる
4. Duration、Delay、Easing、Iteration、Direction、Fill Mode、Pauseを扱う
5. 2D Transform、Opacity、および主要Colorを補間できる
6. Animation中のPaintとHit Testingを同じFrame値へ一致させる
7. hover、class変更、およびWebGo mutationによる開始・中断・再開を扱う
8. navigation、要素削除、Runtime停止時にAnimationを確実に破棄する
9. fake clockを使用して時間依存Testを決定的に実行する
10. active Animationがないときに継続的な再描画を行わない

## 5. CSS Transitions

### 5.1 対応Property

- `transition-property`
- `transition-duration`
- `transition-timing-function`
- `transition-delay`
- `transition` shorthand

Comma区切りの複数Transitionを扱う。各Listの長さが異なる場合はCSS TransitionsのList matching規則に従って値を繰り返し、余分な値を切り捨てる。

`transition-property`は次を扱う。

- `none`
- `all`
- 対応済みの個別Property名

未対応Property名は宣言全体を壊さず、そのPropertyに対するTransitionだけを生成しない。

### 5.2 開始条件

次によって対象PropertyのComputed Valueが変化したときにTransitionを開始する。

- `:hover`、`:focus`、Form Stateの変化
- class、style、attributeの変更
- WebGoによるDOM mutation
- Media Queryの評価変更

初回Style計算ではTransitionを生成しない。同じComputed Valueへの更新、Durationが0秒のTransition、および補間できない値の組み合わせは継続Frameを生成せず、最終値を反映する。

### 5.3 中断と反転

実行中のTransitionへ新しいComputed Valueが指定された場合は、そのFrameで表示されている補間値を新しい開始値としてTransitionを再構成する。

元の開始値へ戻る反転では、すでに進行した割合を考慮して短縮Durationを決定する。毎Frameの補間値を新しいAuthor Styleとして保存せず、underlying valueとanimated valueを分離する。

負のDelayは、開始時点ですでに指定時間だけ進行した状態として扱う。

## 6. CSS Animations

### 6.1 Keyframes

- `@keyframes <custom-ident>`
- `from` / `to`
- `0%`から`100%`までのPercentage selector
- Comma区切りの複数Keyframe selector
- 同じoffsetにあるKeyframe declarationのCascade
- 先頭または末尾Keyframeが省略された場合のunderlying value

無効なKeyframe selectorやDeclarationは局所的に無視し、Stylesheet全体と他のAnimationを停止させない。

### 6.2 対応Property

- `animation-name`
- `animation-duration`
- `animation-timing-function`
- `animation-delay`
- `animation-iteration-count`
- `animation-direction`
- `animation-fill-mode`
- `animation-play-state`
- `animation` shorthand

次の値を扱う。

- `animation-name: none | <custom-ident>`
- `animation-iteration-count: <number> | infinite`
- `animation-direction: normal | reverse | alternate | alternate-reverse`
- `animation-fill-mode: none | forwards | backwards | both`
- `animation-play-state: running | paused`

Comma区切りの複数Animationを同一要素で実行できる。同じPropertyへ複数Animationが値を提供する場合は、後に指定されたAnimationの値を使用する。加算・累積合成は行わない。

### 6.3 Lifecycle

- Animation名または関連Propertyの変更時にAnimationを再構成する
- `paused`では現在時刻を保持し、`running`へ戻したときに同じ位置から再開する
- 要素がDocumentから削除された場合は関連Animationを破棄する
- navigation、reload、Runtime停止時はPageに属する全Animationを停止する
- `display:none`になった要素と子孫のAnimationを終了し、再表示時は適用中の`animation-name`から新しく開始する
- infinite AnimationもPageのLifecycleとCancellationへ従う

`animationstart`、`animationiteration`、`animationend`、`transitionrun`、`transitionstart`、`transitionend`などのWebGo Event公開はv0.7.0の対象外とする。

## 7. TimingとEasing

### 7.1 Clock

Animation Engineはwall clockではなく単調増加するClockを使用する。各Frameの値は前Frameとの差分の累積ではなく、開始時刻と現在時刻から計算し、Frame dropによる時間のずれを蓄積しない。

ClockをInterfaceとして注入可能にし、本番ではGio Frame時刻、Testではfake clockを使用する。

同一Frame内の全Animation、Style、Paint、およびHit Testingは同じtimestampを参照する。

### 7.2 Time Value

- `s`と`ms`
- 0以上のDuration
- 正、0、負のDelay
- finite numberのIteration Count

負のDuration、非有限値、および構文上無効な値は、そのDeclarationだけを無効とする。

### 7.3 Easing Function

- `linear`
- `ease`
- `ease-in`
- `ease-out`
- `ease-in-out`
- `cubic-bezier()`
- `step-start` / `step-end`
- `steps()`の`jump-start`、`jump-end`、`jump-none`、`jump-both`、`start`、`end`

`cubic-bezier()`のx座標は0から1の範囲に制限する。数値解決は決定的とし、Testで許容誤差を明示する。

## 8. 補間とCascade

### 8.1 Animatable Property

v0.7.0では次を補間対象とする。

- `opacity`
- `transform`
- `color`
- `background-color`
- `border-top-color` / `border-right-color` / `border-bottom-color` / `border-left-color`
- `outline-color`

ColorはalphaをpremultipliedしたsRGBとして補間する。`currentColor`はAnimation開始時のComputed Valueへ解決してから補間する。

Transform Listは短いListを対応するidentity Functionで補い、共通するFunctionまたは同じprimitiveの接頭部分を成分ごとに補間する。残りのFunction構造が一致しない場合は2D matrixへ変換して補間する。補間結果が非可逆行列になる時点では要素と内容を描画せず、Hit Testingの対象からも除外する。

### 8.2 Discrete Value

補間対象外Property、互換性のない値、および`display`や`visibility`などの離散Propertyはv0.7.0ではAnimationさせない。通常のCascadeで決まった値を即座に反映する。

### 8.3 Cascade Order

underlying Computed Styleとanimated valueを別に保持する。

- CSS Animationは通常のAuthor Declarationより優先する
- `!important` DeclarationはCSS Animationより優先する
- 実行中のCSS Transitionは、同じPropertyのCSS Animationと`!important` Declarationを含む他のCascade Originより優先する
- Animation終了後はFill Modeに従い、Fillがなければunderlying valueへ戻す

Animationの出力をAuthor Declarationへ書き戻さず、Animation終了後やclass変更後に古い値を残さない。

## 9. Frame更新、Paint、Interaction

- active Animationが存在するときだけ次Frameを要求する
- 1回のFrameで全Animationを同じtimestampまで進める
- animated valueの更新後に必要なDirty Stateだけを設定する
- v0.7.0の補間対象はLayout geometryを変更しない
- ColorとOpacityの変更はLayoutを再実行しない
- Transformの変更はDisplay List、Paint、およびHit Testingへ反映する
- animated Transformの逆行列を使ってPointer座標をlocal coordinateへ変換する
- animated Opacityが0でも、通常のCSSと同様にPointer対象から自動除外しない
- hoverによるTransitionをAnimation Frameごとに再起動しない
- scroll、resize、およびAnimationが同じFrameで発生しても最新状態を一度だけ構築する
- 処理が遅れた場合は過去Frameを順番に描かず、現在時刻へ追いつく

---

## 10. Reduced Motionと安全性

`prefers-reduced-motion: reduce | no-preference`をMedia Queryへ追加する。

- Browser設定から評価値を注入できる
- 既定値は`no-preference`とする
- TestではOS環境に依存せず値を指定できる
- `reduce`時にAnimationを自動削除せず、Author StyleのMedia Queryを尊重する

1要素あたりのAnimation数、Keyframe数、およびStylesheet全体のactive Animation数に安全な上限を設ける。上限超過時は該当Animationを無視し、Growseプロセスと他のPage処理を継続する。

極端なDuration、Iteration Count、Delay、Keyframe offset、`cubic-bezier()`、および`steps()`がpanic、無限loop、busy loop、非有限値の描画Commandを発生させないようにする。

---

## 11. Performance

- active AnimationがないPageではFrameを継続要求しない
- 同一Frame内でNodeごとのStyle再計算とDisplay List再構築を重複させない
- Transform、Opacity、ColorだけのAnimationでLayout Passを実行しない
- Animationの追加・削除を毎Frameの全DOM走査に依存させない
- 終了したAnimationと削除済みNodeへの参照を保持しない
- 100要素の同時Animationを代表WorkloadとしてFrame更新時間とAllocationを計測する
- Frame drop時もDurationとIterationの終了時刻を変化させない

固定FPSだけを完了条件にせず、fake clockによる正確性、active Animation数ごとのFrame処理時間、およびAllocationを継続計測する。

## 12. テスト方針

### 12.1 Unit Test

- TransitionとAnimation shorthand / longhand parsing
- Comma区切りListのmatching
- `@keyframes` selectorとDeclaration
- Duration、Delay、Iteration、Direction、Fill Mode
- cubic bezierとstepsの境界値
- Color、Opacity、Transform、Matrix interpolation
- pause / resumeと負のDelay
- Cascade、`!important`、TransitionとAnimationの優先順位
- 無効値、非有限値、および安全上限

### 12.2 Integration Test

- hoverによるTransition開始と反転
- class変更とInline Style変更によるTransition中断
- WebGo mutationによるAnimation開始・停止
- 複数Animationと複数Propertyの同時進行
- alternate、infinite、Fill Mode、Pause / Resume
- navigation、reload、要素削除時のCancellation
- animated TransformとHit Testing
- scroll / resize中のAnimation
- `prefers-reduced-motion`によるStyle切替

すべての時間依存Testはfake clockを使用し、実時間のsleepやOSの描画速度へ依存させない。

### 12.3 Visual Regression

決定的なFont、Viewport、Scale、およびtimestampを使用し、開始前、Delay中、中間Frame、Iteration境界、終了時のSnapshotを保存する。

pixel hashだけでなく、animated value、Transform Matrix、Display List、Paint順、およびHit Test結果を同時に記録する。

### 12.4 Conformance Test

CSS Transitions、CSS Animations、CSS Easing FunctionsのWeb Platform Testsから対応Featureに必要なTestを選定し、出典、縮約内容、および未対応理由を`docs/wpt.md`とCSS対応表へ記録する。
